## Исправление превью после замечания пользователя

На присланном изображении разделитель касался кнопки, а текст рисовался шрифтом с засечками. Причины в экспортированном HTML: нелayered `p { margin: 0 }` перекрывал отступы внутри `@layer components`; переменные шрифтов задавались на body вместо корня, где вычислялись зависимые переменные; TTF были внешними файлами. В мобильном DOM-адаптере числовой React Native lineHeight ошибочно становился CSS-множителем.

Исправлено только превью: reset перенесён в base layer, переменные шрифтов заданы на :root, шрифты встроены, line-height нативного превью получил px. Продуктовый CSS этой ошибки экспорта не содержал.

Добавлена [галерея](../design/check-questions-2026-11-16/index.html): 9 состояний для web и мобильного DOM-превью, включая выбор подсказки, ожидание, ошибку, предупреждения сегодня/сейчас, лимит и срок. Дополнительные состояния смоделированы в статичных HTML; они не заменяют интерактивную или нативную проверку. Снимки пока не получены. Проверены содержимое 20 HTML-файлов, встраивание шрифтов, слой reset и единицы line-height.
