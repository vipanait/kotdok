# Ревью релизного PR #82 (FB-2…FB-5 и дизайн 20.10)

| Поле | Значение |
| --- | --- |
| Дата | 20 октября 2026 |
| Как | Три ревьюера по областям (сервер и миграции; питомцы и onboarding; медкарта и напоминания), находки проверены по коду |
| Ветка | `feature/fb-5` → `feature/fb-3` (head PR #82) |

## Исправлено

| Находка | Исправление |
| --- | --- |
| Сохранение анкеты старого питомца (только `age_years`) выдумывало дату рождения: «0 лет» → «меньше месяца» | Возраст без даты отправляется как был, пока годы и месяцы в форме не меняли |
| «Прививки и врач»: при ошибке загрузки — «Не удалось сохранить питомца», без выхода | «Не удалось загрузить питомца», «Повторить», «Пропустить», стрелка назад |
| Сбой загрузки одного питомца снимал его напоминания о лекарствах на неделю | Пересборка прерывается, телефон сохраняет прежние напоминания; удалённый питомец пропускается |
| Каждое возвращение в приложение — запрос медкарты каждого питомца | При возвращении — не чаще раза в 10 минут; после изменений в приложении — сразу |
| «Сегодня» после полуночи показывал вчерашний день | День обновляется при возвращении и раз в минуту, приёмы перечитываются |
| «Завершить курс»: при ошибке после снятия времени напоминания оставались | Пересборка в любом исходе |
| Памятка для передержки без времени приёма и без последнего дня курса | «Нефростоп, 1 таблетка (08:00, 20:00)», день окончания включён |
| «Добавить в календарь» у прошедшего плана | Только для сегодняшних и будущих |
| «Знаю дату» → «Примерно» стирал возраст | Годы и месяцы берутся из даты |
| Камера: запрет доступа и ошибка открытия — тишина | Сообщение и «Открыть настройки» |
| Сохранённый путь onboarding у аккаунта с питомцами мог запуститься позже | Закрывается, как только есть питомцы; при выходе из аккаунта ключ удаляется |
| VoiceOver: переключатель «кг / г» читался как «Вес (г)», у спиннера фото нет подписи | «Единица веса», «Сохраняем фото» |
| en «Mark given» мог переноситься | Колонка действия — минимальная ширина, не фиксированная |
| «дали» на любой прошедший день | Только в днях курса и не раньше 14 дней назад (400) |
| `medication_doses` без `refuse_late_writes` | Триггер добавлен, как у остальных таблиц пользователя |
| `reminder_times` принимал NULL, пустой элемент и «08:00,09:00» в одном элементе | Проверка длины: ровно одно «ЧЧ:ММ» на элемент |
| Правка питомца во время удаления аккаунта → 400 | 403 `account_deleting` |
| Дозы курса, удалённого одновременно с отметкой, читались | Только живые курсы |
| Подтверждение фото без лимита | `avatar_confirm`, 30 в час |
| Сайт: `PUT /api/pets/[id]` без проверки тела, невозможная дата → 500 | Контракт `PetUpdateInput`, 400; `invalid` → 400 |
| OpenAPI без новых маршрутов, новые поля питомца обязательные | Фото, время приёма, «дали», журнал, заголовок `X-Lapka-Features`; поля по признаку — необязательные |

## Исправлено вторым заходом (решения владельца)

| Было | Стало |
| --- | --- |
| Аватар моргал при возврате на список: каждая подпись — новая ссылка, новая загрузка | `expo-image`, ключ кэша — путь файла без подписи; меняется только при замене фото |
| Напоминания о лекарствах заканчивались без слова, если приложение не открывали неделю | Последнее уведомление через минуту после последнего запланированного приёма: «Напоминания о лекарствах заканчиваются. Откройте «Лапку»…», пока курс идёт дальше |
| «Напоминания» на карточке, «Все сроки» в ссылке и на экране, «Напоминания» — экран настроек | Всё — «Напоминания» («Все напоминания · N», экран «Напоминания»); экран настроек и строка профиля — «Уведомления»; «появится в напоминаниях» |
| Две миграции датированы 21 октября | `20261020130000_pet_avatars.sql`, `20261020140000_medication_reminders.sql` (на staging и прод ещё не применялись) |

Сайт по-прежнему говорит «Сроки» и «Все сроки»: задание касалось приложения.

На симуляторе (новая отладочная сборка с `expo-image`): фото после смены вкладок на месте ([01](release-pr82-review/01-photo-after-tab-switch.png)); «Все напоминания · 4» ([02](release-pr82-review/02-all-reminders-link.png)); «Уведомления» в профиле ([03](release-pr82-review/03-profile-notifications.png)); экран «Напоминания» ([04](release-pr82-review/04-reminders-screen.png)). Последнее уведомление недели — только юнит-тестом: на симуляторе неделю не ждал.

## Порядок выпуска (обязательно)

1. Три миграции — сначала staging, потом production: новый сервер без них ломает создание питомцев, медкарту и удаление аккаунта.
2. Слияние в main (Vercel).
3. Сборка в сторы: тексты разрешений в `app.json` и нативный `expo-image` меняют fingerprint, по воздуху (EAS Update) этот выпуск до старых сборок не дойдёт.

## Проверки

Приложение 502/502, веб 535/535, интеграционные 499/499, `tsc` чисто, OpenAPI проходит валидатор. На симуляторе исправления не перепроверял: они покрыты юнит- и интеграционными тестами.
