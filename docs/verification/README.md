# История выполнения и проверок

Источник требований: [дорожная карта](../mobile-api-plan.md). Формат подробного отчёта: [REPORT_TEMPLATE.md](REPORT_TEMPLATE.md).

Этап 0 в работе: исходные проверки выполнены, локальный стенд и фикстуры готовы, два пункта заблокированы внешними решениями. PLANNED означает отсутствие принятого результата, а не успешную проверку. Ниже этапы расположены в согласованном порядке исполнения.

Открытые блокеры: нет отдельного тестового проекта Supabase (0/04); не подтверждены хостинг, резервное копирование и runtime worker (0/06); ручной сценарий сайта не пройден. Подробности — в [отчёте этапа 0](stage-0.md) и [docs/architecture/deployment.md](../architecture/deployment.md).

После каждого этапа обновить статус и добавить ссылку на `stage-<номер>.md`. При незавершённой работе сохранить промежуточный отчёт. Записи циклов проверки хранятся отдельно в `runs/stage-<номер>/<YYYYMMDD-HHMMSSZ>.md`, включая неудачные запуски.
