# Оформление «Можно ли это питомцу»: отчёт о дизайн-проходе

Отчёт о проходе, который привёл готовую функцию к макетам `docs/design/pet-safety-v1/`: предметные иконки, карточки с вердиктами, «Если питомец уже съел» первым блоком, короткая подпись с действием «О материалах». Скриншоты лежат рядом, в `pet-safety-design-2026-11-15/` (PNG в `docs/` игнорируются git и есть только на машине владельца).

## Что сделано

**Общее (`packages/shared`).** Имена девяти иконок и правила выбора: известная запись получает свою иконку (шоколад, виноград, молоко, лилия, ибупрофен, парацетамол, яблоко), остальные получают иконку категории. Строки «О материалах» (подпись, действие, заголовок, три абзаца, «Закрыть») на русском и английском.

**Веб (`apps/web`).** Каталог `/mozhno-li`: заголовок с иллюстрацией, поиск с чипами категорий, «Часто спрашивают», «Весь справочник» по категориям, баннер приложения, короткая подпись. Карточка записи: два вердикта виду, блок «Если питомец уже съел» первым, затем «Почему» и «Признаки», справа источники и приложение. Длинная подпись об авторстве заменена короткой.

**Мобильная версия (`apps/mobile`).** Вкладка «Можно ли?»: заголовок, выбор питомца карточкой, чипы категорий с иконками, недавние запросы, карточки позиций с иконками. Карточка записи: пометка аллергии выше вердикта, блок вердикта, «Если Рекс уже съел» с красной полосой при `call_now`, «Почему», «Признаки», строка «А для кошки?», «На чём основан ответ» с рабочими ссылками. Экран ответа ИИ, состояния «загрузка», «ошибка», «лимит», «не распознано», «нет совпадения» и пустой каталог.

## Ручные проверки

**Веб.** Preview-сборка (`VERCEL_ENV=preview`) на 5 ширинах: каталог, поиск с опечаткой, поиск по алиасу, категория, категория с запросом, «нет в справочнике», шоколад (опасно), морковь (безопасно), яблоко (осторожно), лилия (разные вердикты видам), кукуруза (разные «если съел»), черника (`none` у одного вида), ибупрофен (лекарство), силикагель (бытовое, малый риск). Production-сборка без `VERCEL_ENV`: пустой каталог, все записи `agent_reviewed`, страница `noindex`. Исполнитель: агенты реализации D2; повторная проверка после правок ревью проведена на 1440 и 390.

**Мобильная версия (iOS).** Исполнитель: агент реализации D3. Устройство: iPhone 17 Pro, iOS 26.5, Debug `my.lapka.app` 1.2.1, JS из Metro этого worktree. Тестовые данные: пользователь owner-a (вход по magic link), собака Рекс, кошка Мурка, аллергия Рекса «курица» (временно), две строки кэша `safety_ai_answers` с `model = d3-test-fixture` (`мелатонин`/собака = опасно с `call_now`, `кумкват`/собака = нет данных), лимит `safety_ask:<owner-a>` на время кадра 32. Все временные данные после проверки возвращены, `apps/mobile/.env.local` удалён, `apps/web/AGENTS.md` восстановлен. Настоящих обращений к ИИ было два (`zzqx vlorb`, `кумкват` для кошки); после этого API запущен с поддельным ключом, симптомы не отправлялись. ## Отличия от макета

**Веб** (приняты в ревью D2).
- Шапка сайта прежняя (`PublicHeader`), по §6 handoff.
- H1, eyebrow и вводный текст каталога остаются прежним SEO-текстом; h1 записи остаётся вопросом «Можно ли кошкам и собакам шоколад?», на нём построены title, FAQ JSON-LD и тесты.
- Под «Часто спрашивают» добавлен полный список «Весь справочник» по категориям, он всегда есть в HTML сервера (§6: шесть позиций макета только пример).
- Призыв: прежние пути (регистрация, App Store и Google Play) вместо одной кнопки «Открыть приложение»; текст сохраняет честные слова про аллергию и хронические болезни. Заголовок боковой карточки «Проверьте для своего питомца».
- Карточка источников называется «Источники»; видимая подпись поля заменена скрытой, как в макете; до гидратации чипы категорий это ссылки, поля нет (прежнее правило сайта).
- Нет состояний «загрузка» и «ошибка» (поиск локальный); «не найдено» это встроенное «Пока нет в справочнике» со «Сбросить поиск», «неопубликовано» это пустой каталог со ссылкой «Что делать при отравлении».
- Первые шаги остаются нумерованным списком, признаки маркированным.
- Безопасный вердикт бирюзовый (`home_care`), по §4 и макету.

**Мобильная версия** (приняты в ревью D3).
- У экранов записи и ответа остался нативный заголовок `Screen` (стрелка и название) вместо ссылки «← Можно ли питомцу»; eyebrow «ПРОДУКТЫ · СПРАВОЧНИК» стоит под названием.
- Карточка «Для кого смотрим» на экранах записи и ИИ не интерактивна: питомца выбирают на экране поиска, другой вид открывает «А для кошки?».
- Нет ссылки «Справочник» рядом с «Часто спрашивают» (в приложении нет такого экрана, мёртвые ссылки запрещены §8).
- В поле поиска нет лупы (общий `Field` её не имеет, менять общий компонент не стали).
- Состояния «нет в справочнике», лимит, ошибка и «не распознано» остаются внутри своих экранов; при нераспознанном запросе поле остаётся редактируемым с «Спросить ИИ», вместо единственной кнопки «Изменить запрос» (§7).
- Заголовок экрана ИИ это название ответа, не «Ваш запрос»; метка прежняя «Ответ ИИ, не из справочника»; при загрузке заголовок это запрос.
- Строка расхода прежняя «Проверка расходует 1 кредит»; «Если Рекс уже съел(а)» в прежней нейтральной форме.
- Безопасный вердикт бирюзовый, как в вебе. Кнопка проверки сохраняет прежние виды: вторичная под `call_now`, основная под `watch`.
