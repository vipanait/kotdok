## Вакцинация в анкете (спецификация §4)

`pets.vaccinated` — итог: «да», если есть сделанная прививка, иначе ответ владельца. Сам ответ хранится отдельно в `pets.vaccinated_form`. Анкета и ИИ-проверка читают `vaccinated` без изменений. Удаление последней прививки возвращает ответ владельца, а не «не привит». Интеграция: «marks the pet vaccinated once a vaccination is done…», «keeps "vaccinated" while records say so…».

## Идемпотентность

Каждая форма посылает свой `Idempotency-Key`. Повтор с тем же ключом и теми же данными возвращает первую запись. Тот же ключ с другими данными — 409, форма пишет «Эта запись уже сохранена раньше, без последних изменений». Пустой ключ — 400. Плановая запись, превращённая в сделанную, сохраняет свой ключ. Интеграционные тесты на все четыре случая.

## Ревью

Независимое ревью `b3f563b..7472fd3`. Исправлено в `aaa8f64`, каждое — тестом, который сначала падал:

1. `pets.vaccinated` не отражал сделанные прививки (§4) — теперь отражает, ответ владельца сохраняется отдельно.
2. «Через год» и следующий срок могли создать план в прошлом — отклоняется сервером; в форме «Через год — уже прошла, не напоминать».
3. Тот же ключ с другими данными молча возвращал первую запись — теперь 409.
4. Завершение одиночного плана перезаписывало его ключ — ключ сохраняется.
5. Пустой ключ считался ключом — 400.
6. «Просрочено с 23 июля · 23 июля» — дата больше не повторяется.
7. Диктор не слышал статус срока у карточки плана; шторку «Что добавить?» нельзя было закрыть жестом VoiceOver.

## Решения по ходу этапа

- Сроки для списка питомцев — отдельный `GET /pets/due` (все питомцы одним запросом), а не `GET /pets/{id}/health/due` из плана: списку нужен один запрос, не N.
- Сроки одной даты из одной сделанной записи попадают в одну плановую запись; независимость позиций обеспечивает отметка «Сделано» по позиции.
- В «Сделано» по сроку переключатель «Сделано / Запланировать» не показывается: это отметка конкретного плана.
- Справочник вакцин — в MR-04; сейчас название свободное, болезни — чипами по виду питомца.
- В «Что добавить?» только прививка и вес: остальные виды записей появятся в своих этапах.
- Строка срока в списке питомцев: «…— просрочено» без числа дней, как в §7.1.

## Отложено (мелкое)

- Гонка PATCH-даты: статус записи читается до блокировки; если план успели отметить сделанным между чтением и записью, сделанную запись можно сдвинуть по правилу плана.
- В списке раздела «Прививки» у плановой карточки нет кнопки «Сделано» (§7.5) — отметка доступна из просмотра и из «Сроков».
- Сервер принимает болезнь другого вида (собачью у кошки); форма такого не предлагает.

## Ограничения

- Ввод дат — текстом «ДД.ММ.ГГГГ» (как в MR-02). В симуляторе раскладка клавиатуры переключилась на русскую и ломала ввод даты, поэтому перенос плана проверен интеграционным тестом, а не вручную.
- Только iOS-симулятор; Android, физическое устройство, шрифт 200% и 360 × 640 не проверялись.
- Порядок выкладки: миграция MR-03 до сервера, сервер до мобильного обновления.
