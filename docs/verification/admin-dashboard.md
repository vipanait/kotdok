## Что сделано

Раньше страница выбирала `profiles` и `symptom_checks` построчно и считала в Node. PostgREST отдаёт не больше 1000 строк, поэтому при росте базы итоги и графики молча занижались бы. Теперь каждая вкладка — один или два вызова SQL-функций, которые возвращают готовые числа.

| Файл или компонент | Что изменено | Зачем |
| --- | --- | --- |
| `supabase/migrations/20261105120000_admin_overview_stats.sql` | `admin_msk_date`, `admin_metric`, `admin_ratio`, `admin_activity`, `admin_overview_stats` | Общие правила (окна, московские сутки, «нет данных», неактивные аккаунты) и Обзор |
| `…120100_admin_users_stats.sql` | `admin_users_stats` | Аккаунты, активные, активация, возвраты, способ входа, язык, когорты |
| `…120200_admin_checks_stats.sql` | `admin_check_row`, `admin_checks_stats`, `admin_check_feed` | Срочность по дням, вид питомца, анкета, сбои, просьбы, лента проверок без данных владельца |
| `…120300_admin_feedback_stats.sql` | `admin_feedback_stats`, `admin_feedback_feed` | Оценки, доля 👍, по срочности, лента комментариев |
| `apps/web/src/server/admin/{statistics,map}.ts` | Тонкий слой над RPC | Разбор `jsonb` в типы; старый счёт в Node удалён |
| `apps/web/src/app/(frontend)/admin/statistics/**` | Четыре страницы и общая охрана `load-admin-page.ts` | Каждая вкладка проверяет роль сама |
| `apps/web/src/features/admin/*` | Каркас вкладок, плашки, графики, ленты, когорты, анкета | Интерфейс по одобренным макетам |
| `apps/web/src/shared/i18n/*` | Тексты ru/en, срез `admin` + `check` | Подписи ответов анкеты берутся из формы проверки |

## Решения и отклонения

Все решения, принятые при реализации, записаны в журнале выполнения и перечислены в описании PR. Главные:

- Охрана страниц лежит рядом с маршрутами, а не в `src/server`: архитектурный тест проекта запрещает `redirect` в серверном слое.
- «Показать ещё» увеличивает `?shown=` (шаг 50, до 500) вместо курсора: страница остаётся серверной.
- Плашка может показывать одновременно изменение и пояснение (сбои: изменение и коды ошибок).
- Изменение «проверок на человека» считается в процентах между двумя значениями, а не в п.п.
- Срез словаря `admin` теперь включает `check`.

## Непроверенное и риски

- Цифры на продовых данных не сверялись: читать прод без разрешения владельца нельзя.
- Удалённые аккаунты задним числом уменьшают прошлые цифры. Владелец согласен, на страницах есть сноска.
- Платформа регистрации (web, iOS, Android) не записывается. Владелец 5 ноября решил её пока не делать.
