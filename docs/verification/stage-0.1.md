## Что сделано

- Next.js перенесён в `apps/web` через `git mv`; поведение сайта не менялось.
- Настроены npm workspaces с единым корневым lockfile; `npm ci` воспроизводится побайтово.
- Созданы каркасы `packages/contracts` и `packages/shared`; веб берёт из shared список локалей, поэтому пакет проверяется и production-сборкой, а не только тестами.
- Создано минимальное Expo-приложение `apps/mobile`, экспортирующее JS для iOS и Android.
- Проверки и сборочные настройки разделены по приложениям; корневой `.gitignore` покрывает вложенные приложения.
- CI разделён на группы web и mobile с проверяемой логикой маршрутизации.
- Обновлены README и AGENTS.md.

## Решения и отклонения от плана

1. **React Native зафиксирован на 0.86.3, а не на последней 0.87.1.** Expo SDK 57 бандлит 0.86.3; в 0.87 перемещены файлы, которые требует `@expo/metro-config`, и экспорт падал. React 19.2.4 удовлетворяет и Next.js, и React Native — одна версия на весь репозиторий не навязывалась, совместимость проверена.
2. **Корневой `overrides` для react-native.** `@expo/cli` объявляет его необязательным peer с диапазоном `*`, из-за чего npm поднимал в корень вторую копию.
3. **Lockfile собран инкрементально.** Полное разрешение с `overrides` обновляло 166 пакетов, включая Supabase, OpenAI, Vitest и ESLint-тулчейн. Это запрещено пунктом 0.1/02, поэтому lockfile восстановлен из коммита переноса и дополнен только новыми мобильными зависимостями.
4. **Логика маршрутизации CI вынесена из YAML** в тестируемый скрипт, чтобы её можно было менять без наблюдения за прогонами GitHub. Это дополнение к плану, а не замена приёмке 0.1/05.
5. **Интеграционные тесты подключены к CI** через `supabase/setup-cli` и `supabase start`; фактический прогон в CI не наблюдался.

## Известные ограничения

- Версия Node в CI (20) и локально (25.2.1) не согласована; выбор совместимой версии не зафиксирован.
- Экспорт JS не подтверждает нативную сборку. Подписанные development builds и запуск на реальных устройствах — этап 4.
- `apps/mobile` содержит экран-заглушку; авторизация и продуктовые экраны начинаются с этапа 4.
