## Решения и отклонения

- **FB-2/03:** вместо «плана по возрасту из справочника» — предложение осмотра. Расписания по возрасту нет, а без ветеринара его не добавить (MR-04). Критерий в roadmap поправлен.
- **Прививка без даты** записью не становится (у записи дата обязательна), но ставит «привит(а)» в анкете. Для этого шаг отправляет анкету целиком, как экран редактирования: `PATCH /pets/:id` пишет все поля формы сразу (см. «Замечено попутно»).
- **Будущие даты** проверяет маршрут через `isFutureDay`, а не поле `today` в контракте: у сервера свой день с запасом на часовые пояса.
- **Возраст на экране** — полные годы («4 года»), в анализе — с десятыми. Старые питомцы с одним возрастом при первом сохранении анкеты получают примерную дату рождения.
- **Выпуск:** ветка не попадает в `main` до большого обновления приложения (решение владельца от 20 октября; память проекта).

## Ошибки и повторные проверки

- Параллельный сеанс (межстрочный интервал, PR #80) держал Metro 8081, API 3100 и симулятор iPhone 17e. Мой первый запуск ушёл на его бандл, а мой `supabase db reset` стёр его тестовые данные. Сеанс предупреждён; проверка перенесена на iPhone 17 и API 3200 после того, как он освободил 8081.
- Поле даты на iOS не расставляет точки само: «01022024» отклонено у поля «В семье с». Дата выбрана календарём. Сообщение об ошибке ушло под кнопку «Сохранить», видна только красная рамка.
- Поздравление сначала показывалось со значком предупреждения; заменён на лапку.

## Непроверенное и риски

- Android, VoiceOver/TalkBack, английский язык в симуляторе.
- Интеграционные тесты не перезапускались после Task 3–6 (они затрагивали shared и mobile; серверный код после Task 2 менялся только в анализе и `load-check-pages`, покрытых юнит-тестами).
- Сайт: форма сайта дат не показывает и не шлёт; правка возраста на сайте стирает дату рождения (намеренно).

## Замечено попутно

- `PATCH /api/v1/pets/:id` пишет все поля анкеты сразу (`sanitizePet` заполняет отсутствующие пустыми): частичный запрос вроде `{ vaccinated: true }` сбросил бы остальные поля, а имя заменил бы на «Кот». Приложение и сайт всегда шлют форму целиком, поэтому сейчас это не проявляется. Стоит отдельной задачи.
- В «Важно знать» и сводке для врача списки по-прежнему склеиваются через запятую (из FB-1).
