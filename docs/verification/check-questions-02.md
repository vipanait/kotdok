## Что сделано

Под карточкой «Подробности проверки» на странице сохранённого результата появился блок «Уточнить по этой проверке»:

- счётчик вопросов и срок;
- три готовых вопроса по срочности (подставляются в поле, но не отправляются);
- поле и кнопка «Спросить»;
- переписка;
- фиксированная плашка под тревожным ответом с кнопками «Найти клинику» и «Проверить снова»;
- закрытые состояния и сообщение об ошибке.

Блок говорит на языке проверки.

| Файл | Изменение |
| --- | --- |
| `features/symptom-check/CheckQuestions.tsx`, `check-questions-view.ts` | Компонент и его правила: подсказки, счётчик, открыт ли блок по часам браузера, текст плашки, ссылка повторной проверки (у открытого случая — `/check?pet=…&case=…`) |
| `server/checks/load-question-pages.ts`, `app/(frontend)/check/[id]/page.tsx` | Нить читается вместе со страницей; при ошибке блок не показывается |
| `features/symptom-check/CheckResultContent.tsx` | Импорт, проп `questions` и одна строка вставки |
| `app/styles/check-questions.css`, `globals.css` | Стили из токенов дизайн-системы; плашка берёт цвета уровней `urgent` / `emergency` |
| `shared/i18n/dictionaries/{ru,en}.ts` | Срез `checkQuestions` |

## Решения и отклонения

- В русской плашке нет имени питомца («Покажите питомца врачу сегодня»): имя пришлось бы склонять («Покажите Мурку»). В английской имя есть.
- По итогам ревью: ответ 409, пока нить открыта, говорит «Ответ на этот вопрос ещё готовится. Обновите страницу через минуту.». Прежнее «Вопрос не потрачен — попробуйте ещё раз» было бы неправдой: вопрос в работе и будет засчитан. Проверено тестами `conflictNotice`, в браузере после правки не перепроверялось.
- Нить рендерится списком `ol`. Правила `.result-layout ol/li` давали ему отступ и приглушённый цвет. Стиль вопросов теперь выше по специфичности (`1a704a8`).
