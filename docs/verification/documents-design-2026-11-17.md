## Что нужно от сервера (DOC-2), чтобы включить распознавание

1. Флаг «распознавание доступно» в ответах `GET /pets/{id}/documents` и чтения документа, например `recognition_available`. Цена и остаток уже есть в контракте (`recognition_price`, `free_recognitions_left`).
2. `POST /pets/{id}/documents/{docId}/recognition` — ответ 202; ошибки 402 `insufficient_credits`, 409, 429.
3. Чтение документа с опросом во время `recognizing`:
   - `failure_code` (`nothing_found` или другой);
   - `draft` в форме `RecognitionDraft` из `packages/shared/src/documents/review.ts`, включая `duplicate.record_id` настоящего совпадения.
4. `POST …/confirm`:
   - с `Idempotency-Key`;
   - тело `ConfirmBody`;
   - ответ — созданные записи (для честной сводки, где две вакцины могут стать одной записью).
5. `DELETE …/recognition` — отказ от черновика; файл остаётся.
6. `source_document_id` в ответах записей медкарты (колонки и миграция из плана DOC-2).
7. Дозагрузка страниц в сохранённый документ для «Добавить другие страницы», например `POST …/documents/{docId}/files`. Сейчас кнопка в предпросмотре неактивна и подписана.
8. Страница проверки по `documentHref.review` на сайте и маршрут в приложении, которые соединят готовые компоненты с API.

## Что ещё зависит от владельца

- **PDF в приложении:** `npx expo install expo-document-picker` и новая сборка в сторы. Кнопка «Выбрать PDF» появится в такой сборке сама, менять код не нужно.
- **Тексты разрешений в `app.json`:** предложены, но не изменены — `runtimeVersion` считается по отпечатку, и правка сломала бы EAS Update для установленных сборок. Предложенные тексты — в отчёте мобильной части. Менять вместе со следующей сборкой.
- **«Пополнить баланс» на iOS:** экрана пополнения в приложении нет, а продажа проверок подпадает под правила App Store. Нужно решение владельца.
- **Next.js:** сборка один раз остановилась с сообщением `SecurityFatalError` и предложением запустить `next upgrade --agent=security`. Повторная сборка прошла. Обновление не запускалось — решение за владельцем.
- **Миграции** `20261116140000`, `20261116150000` применены к общей локальной базе вручную. Новых миграций в этой работе нет.

### Глазами

Только браузер: локальная продакшен-сборка `next start` против локальной базы, панель браузера в приложении Claude. **Нативных снимков нет:** на этой машине нет ни одной среды iOS-симулятора (`xcrun simctl list runtimes` пуст), Android SDK и react-native-web. Мобильные экраны проверены только чтением кода — два независимых ревью, все важные замечания исправлены — и юнит-тестами. Визуальная проверка приложения **не пройдена**.

Проверено в браузере:
- ширины 320, 390, 1024 и 1280; на 320 без горизонтальной прокрутки;
- длинные имена файлов и препаратов переносятся;
- перестановка страниц обновляет номера и порядок отправки, фокус идёт за страницей;
- удаление всех страниц возвращает оба способа выбора и отключает «Сохранить»;
- после выбора фото PDF не предлагается;
- отказ сервера на PDF с паролем показан точной причиной;
- лимит 20 загрузок в час срабатывает (`429`);
- 30 документов — лимит, кнопка добавления скрыта;
- нет сети (запрос заблокирован в браузере) — «Повторить»;
- удаление — подтверждение с текстом про сохранённые записи, кнопки стопкой на телефоне;
- в проверке записей: счётчик выбранного, 0 выбранных отключает кнопку, неуверенная запись без даты не отмечается;
- возврат из оригинала сохраняет выбор, прокрутку и фокус;
- форма правки без внешней рамки, «Готово»/«Отмена» стопкой;
- «Из документа» без номера страницы.

Не проверено: экранная клавиатура, системный крупный шрифт на телефоне, VoiceOver/TalkBack, системный просмотрщик PDF и возврат из него, настоящая камера и галерея, свайп назад.
