# Проверка мобильной концепции Follow Up Loop

Только макеты, без изменений Expo, API и данных. Этап реализации не закрывается.

- 27 экранов × 390/320 px: 54 проверки геометрии и шрифтов.
- Отметка, питомцы, хронология: текст 200%, ещё 3 проверки.
- Все 57 проверок без горизонтального переполнения и ошибок JS; шрифты загружены.
- Экспортированы 27 видимых экранов 390 × 844 и 27 полных PNG, дополнительный экран для собаки, три увеличенных варианта и общий обзор.
- Проверены: выбор ответа, переход к итогу, локальное сохранение в медкарту для двух видов; вопрос о визите обязателен перед отправкой.
- Визуально просмотрены отметка, список питомцев, полный срочный результат и обзор ключевых экранов.
- Ограничения: прототип в браузере, реальный системный диалог/уведомления/клавиатура не проверялись; непоказанные состояния перечислены в screen-map.md.

Воспроизведение: `node docs/design/followup-loop-mobile-v1/render.cjs`. Данные проверки: `docs/design/followup-loop-mobile-v1/render-report.json`.
