Что проверялось: две клетки матрицы 7/02, которые 8 сентября не снимались отдельно
([прогон](20260908-142500Z.md)) — **серверная ошибка** на экранах «История питомца»
(`(tabs)/pets/[id]/checks`) и «Дополнительная проверка» (`(tabs)/profile/extra-check`).

## Окружение

- Код: `main` на `74127d0`.
- Симулятор iPhone 17e, dev-client, сборка `expo run:ios`, язык устройства английский.
- Supabase — **локальный стенд** (`supabase start`), не staging и не production. В нём
  создан одноразовый пользователь `stage7-02-…@example.test` с питомцем; вход — ссылкой
  `lapka://auth/callback#access_token=…` с токенами этого пользователя, без ввода пароля
  в приложении.
- API — одноразовая заглушка вне репозитория: на любой запрос `500` с конвертом
  `{"error":{"code":"internal_error",…}}`. Слушала порт 3000 по адресу из
  `apps/mobile/.env.local` (`192.168.0.206:3000`).

**Заметка на будущее.** Переопределить `EXPO_PUBLIC_API_URL` переменной окружения при
запуске Metro не получилось: в dev-режиме `expo/virtual/env` подмешивает значения из
`.env.local` поверх `process.env` (в бандле это модуль `.env.local`), и даже
`EXPO_NO_DOTENV=1` этого не отключает. Проще поставить заглушку на адрес из файла.
