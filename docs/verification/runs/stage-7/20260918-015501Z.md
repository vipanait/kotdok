## Что мешало проверять

Сборка iOS не линковалась с момента, как `ios/` была перегенерирована шаблоном
Expo 57 (PR #38): шаблон берёт предсобранное ядро React Native, а автолинковка
подтягивала `react-native-gesture-handler` и `react-native-reanimated` — их
ставит npm как peer-зависимости drawer из `expo-router`. Ошибка — `Undefined
symbols: facebook::react::Sealable`. Приложение работает на нативном стеке и ни
один загружаемый им модуль их не импортирует (`js-stack` не используется), так
что они исключены из автолинковки — `6b7294d`.

Второе: запущенный до правки контракта `next dev` продолжал отвергать новое
значение `4-7days` с `400`. Лечится перезапуском dev-сервера; на самой правке
это не сказывается.

## Проверено на экране

| Что | Как проверялось | Результат |
| --- | --- | --- |
| Ошибка снимается при правке | Вход: пустая отправка, затем ввод; проверка: «хотя бы 3 символа», затем 50 символов | Баннер и подпись пропадают с первым символом |
| Сообщения о полях | Вход без пароля → «Enter a password»; адрес без `@` → «Check the email address» | Каждый экран называет своё поле |
| Соглашение и пароль | Экраны входа и регистрации | Строка со ссылкой на `/legal` есть на обоих; под паролем при регистрации — «At least 6 characters» |
| Пустой список питомцев | Новый аккаунт без питомцев → добавление первого → возврат в список | Показан сразу список с питомцем, старое пустое состояние не мигает |
| Имя питомца на шаге 1 | Проверка с одним питомцем | «Питомец · Tom» |
| Длительность 4–7 дней | Шаг 2 | Четыре кнопки в ряд, «Больше недели» в две строки; значение доехало до результата |
| Уход с экрана ожидания | Отправить проверку → сразу вкладка «Питомцы» → дождаться `202` и `check-jobs` в логе → вернуться на «Проверку» | Не выдёргивает из другой вкладки; при возврате открывается готовый результат; повторный заход показывает форму, а не тот же результат |
| Сброс вкладки | Профиль → История → результат → «Новая проверка» → вкладка «Профиль» | До правки профиль открывался на результате; после — на корне |
| Результат | Тот же результат | Дата со временем сверху, ответы шага 2 в «Что вы описали», кнопка «Новая проверка» внизу, видовое предупреждение в нейтральном блоке |
| История | Профиль → История проверок | Заголовок совпадает с пунктом меню, у записей дата и время |
| Отмена нового питомца | Ввести имя → «Отмена» | «Не сохранять питомца?» с «Не сохранять» и «Продолжить» |
| Текст удаления | Профиль → Удалить аккаунт | В «Что останется» — записи о начислении и списании проверок, платежей больше нет |
| Баннер «Язык сохранён» | Смена языка, снимки экрана | Исчезает сам; прежнего «висит, пока жива вкладка» нет |
| Согласованность ответа AI | Две проверки на staging | «Наблюдаем» с текстом про наблюдение, «Срочно» с текстом про 24 часа — расхождения, найденного 17 сентября, не повторилось |
