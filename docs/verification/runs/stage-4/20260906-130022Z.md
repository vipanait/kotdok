## Ещё раз про инструмент проверки

Синтетический ввод продолжает мешать. Нажатие по ссылке «Создать аккаунт» дважды не сработало вовсе — экран пришлось открывать через `simctl openurl`. Ввод адреса терял хвост после `@`: в поле оставалось `m2`. Пришлось дописывать текст вторым заходом.

Само приложение при этом ведёт себя правильно каждый раз, а ручной ввод владельца проходит с первой попытки. Для пункта 3.4 это второе подтверждение: инструмент E2E надо выбирать по надёжности ввода и по способности адресовать элементы, а не координаты.
