## Версии зависимостей

Одна физическая копия React — `node_modules/react` 19.2.4, общая для Next.js 16.2.3 и React Native. `npm ls react --workspace @lapka/mobile` показывает только `19.2.4 deduped`. Одна копия `react-native` 0.86.3.

Два конфликта пришлось разрешать явно:

1. **React Native 0.87.1 несовместим с Expo SDK 57.** `@expo/metro-config` требует `react-native/rn-get-polyfills`, которого в 0.87 нет; экспорт падал сразу. Expo SDK 57 в `bundledNativeModules.json` объявляет 0.86.3 — на неё и зафиксировано.
2. **Дубль react-native.** `@expo/cli` объявляет `react-native` необязательным peer с диапазоном `*`, поэтому npm поднимал в корень свежий релиз рядом с закреплённым 0.86.3. Добавлен корневой `overrides`.

`overrides` применяется только при полном разрешении зависимостей. Полная пересборка lockfile обновила **166 пакетов**, включая `@supabase/supabase-js` 2.103.0 → 2.115.0, `openai` 6.34.0 → 6.49.0, `resend` 6.10.0 → 6.26.0, `vitest` 4.1.5 → 4.1.11, `tailwindcss` 4.2.2 → 4.3.3 и `typescript-eslint` 8.58.1 → 8.69.0. Это то самое необязательное обновление, которое пункт 0.1/02 запрещает совмещать с переносом; вариант отклонён.

Итоговый lockfile собран **инкрементально** поверх зафиксированного веб-only lockfile коммита `8361399`. Ни одна прямая зависимость веба не изменилась. Изменились 22 транзитивных пакета, все — patch/minor в пределах прежней мажорной версии, поднятые диапазонами самой Expo: `@babel/*` 7.29.0 → 7.29.7/7.29.8, `browserslist` 4.28.2 → 4.28.9, `caniuse-lite`, `electron-to-chromium`, `node-releases`, `nanoid` 3.3.11 → 3.3.18, `postcss` 8.5.13 → 8.5.28, `update-browserslist-db`, `baseline-browser-mapping`. Полный список — в diff lockfile коммита.

Промежуточная попытка удалить из lockfile только записи семейства react-native дала единственную копию 0.86.3, но вложенную в `apps/mobile/node_modules`. При этом корневой `babel-preset-expo` перестал находить `@react-native/babel-plugin-codegen`, и оба экспорта упали. Вариант отклонён; зафиксирован здесь, чтобы к нему не возвращались.
