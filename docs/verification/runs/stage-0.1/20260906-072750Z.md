### Preview после переноса

Первый push ветки дал **упавший** preview `kotdok-joo4ecu01`: сборка прошла, но Vercel искал `/vercel/path0/.next`, тогда как выход теперь в `apps/web/.next`. Production при этом не затронут — `lapka.my` продолжает отдавать сборку из `main` 32-дневной давности.

Добавлен корневой `vercel.json` (`framework: nextjs`, `installCommand: npm ci --workspace @lapka/web --include-workspace-root`, `buildCommand: npm run build --workspace @lapka/web`, `outputDirectory: apps/web/.next`). Настройка живёт в репозитории, а не в параметрах проекта, поэтому воспроизводится вместе с кодом. Следующий preview `kotdok-2bjzr7y6r` — статус **Ready**, длительность 1 минута.
