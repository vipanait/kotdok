## Ревью

Независимое ревью диапазона `8765341..6ab8a2a`. Исправлено в `53cca73`:

1. Ответ медкарты больше не строгий: поля, которые добавят следующие этапы, не ломают уже установленное приложение. Раздел открывается только если он записываемый на сервере **и** у сборки есть его экран (тест «does not open a section this build has no screen for»).
2. В шапке всегда вид животного: «Собака» вместо «Сука» из анкеты, "Cat" вместо "Female" (тест «names the species even when the sex is known»).
3. При ошибке загрузки медкарты «Анкета» и история проверок остаются доступны (проверено в симуляторе).
4. Текстовые ссылки не уже 44 pt.

Отложено как мелкое: удалённый на другом устройстве питомец остаётся под баннером ошибки до ухода с экрана; нет защиты от гонки двух загрузок при быстрой смене фокуса; тест неактивного аккаунта проверяет «не 200», а не точный код 403.

## Решения по ходу этапа

- Разделы в MR-01 — строки без шеврона и без нажатия: их экраны появятся в своих этапах. Кнопки «Добавить запись» и «Для врача» скрыты, пока нечего добавлять и нечего сводить.
- Строка истории проверок — без счётчика: API истории не отдаёт общее число, а считать страницами ради одной цифры не стоит.
- Подсказки под полями анкеты (M27) не показываются: они появляются только при записях в медкарте, а записей пока нет.
- «Стерилизована» — отдельной строкой под метой, как в макете M2 (спецификация §7.2 ставит её в конец строки меты; макет новее).
- В медкарте есть строка «В анкете: не привит(а)» для ответа «Нет» — её нет в таблице §7.2, но это правдивый ответ анкеты.

## Ограничения

- Порядок выкладки: сервер с `/pets/{id}/health` должен выйти раньше мобильного обновления. Иначе медкарта покажет ошибку загрузки; анкета и история при этом доступны.
- Проверено только на iOS-симуляторе; Android и физическое устройство не запускались.
- Увеличенный шрифт 200% и экран 360 × 640 не проверялись в этом этапе.
