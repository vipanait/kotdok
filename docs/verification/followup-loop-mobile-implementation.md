## Что сделано

| Часть | Изменение |
| --- | --- |
| `features/followup/FollowupOffer.tsx`, `CheckResult.tsx` | «Напомнить, как …?» на результате: monitor/home_care — после клиники, перед рекомендациями; urgent/emergency — после «Записать визит», выключено. Первый показ записывает предложение (`off` или включено). Если у питомца уже идёт другой случай — выключено с предупреждением. Строка «Разрешить» и своя шторка перед системным запросом; при запрете — «Открыть настройки». Повторная проверка показывает «Часть случая от …» |

| `features/followup/CaseTimeline.tsx`, `CheckHistory.tsx` | Хронология случая: проверки, отметки, визиты, закрытие; «Отметить сейчас», «Не напоминать больше» с подтверждением, «Записать в медкарту». История — одна строка на случай с исходом |

| `reminders/sync.ts`, `followup-reminders.ts`, `ReminderProvider.tsx` | Уведомления случаев в общем планировщике: первыми в лимите iOS, ночной вопрос в 09:00, без симптомов в тексте, данные `{kind: followup, caseId}`; тап ведёт на отметку для своего владельца и живого питомца. ## Выпуск

Новых нативных модулей, плагинов и разрешений нет. Но в main уже есть `expo-store-review` (#86), которого нет в сборке 1.1.0 из сторов: следующий выпуск мобильной пачки всё равно требует сборки. После неё фича обновляется через EAS Update.

## Непроверенное

- Android: эмулятор и планшет не подключались.
- Физический iPhone, VoiceOver, 200 % текста, 320 pt.
- Тап по уведомлению в центре уведомлений — только юнит-тест.
- Отправка повторной проверки — локально нет ключа модели; серверная часть покрыта `followup-03.test.ts` с подменённой моделью.
- Первое касание по кнопке «Отметить» при открытой клавиатуре закрывает клавиатуру, а не отправляет — так ведут себя все формы приложения (`Screen`), отдельно не менялось.
