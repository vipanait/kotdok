## Как анкета и курсы держатся вместе

- `pets.medications` — названия текущих курсов: без окончания или с окончанием позже сегодняшнего дня. Курс, закончившийся сегодня, уже не текущий.
- Сохранение анкеты сравнивает новый список с тем, что анкета показывала. Добавленное начинает курс сегодня, убранное завершает курсы этого названия сегодня. Не начавшийся курс при удалении из анкеты удаляется совсем.
- Анкета меняет курсы, только если в запросе есть поле `medications`. Частичное обновление питомца их не трогает.
- Название, которое есть в списке, но без курса (записано старым сервером), сначала становится курсом без даты начала.
- Обзор медкарты не показывает курс, истёкший после последней записи.

## Ревью

Независимое ревью `59f9001..cc12491`. Критичных нет. Пять важных и часть мелких исправлены в `461c40e`, каждое — тестом, который сначала падал:

1. Список анкеты устаревал со временем. Кроме того, «Завершить курс» к востоку от UTC не убирал название.
2. Название в списке без курса терялось при следующей записи.
3. Частичное обновление питомца завершало все курсы. Вызвано уже известной ошибкой частичного PATCH (задача заведена отдельно), здесь закрыто на стороне курсов.
4. Анкета завершала курсы, добавленные в медкарте после её загрузки; не начавшийся курс получал однодневную жизнь.
5. Перенос в миграции упал бы на аккаунте в статусе удаления.

Мелкие исправлены:
- регистр в названиях;
- ключ пачки привязан к питомцу;
- создание питомца не отвечает ошибкой после вставки;
- гонка правки отвечает 400, а не 500;
- «Завершить курс» не показывается у не начавшегося курса;
- «Важно знать» считается по курсам;
- проверка длины в форме;
- сообщение при ошибке загрузки.

## Решения по ходу этапа

- Дата для записей из анкеты — день телефона (поле `weight_measured_on`); для записей из медкарты — день сервера. «Завершить курс» использует день телефона.
- Удаление курса целиком оставлено для ошибочных записей. Диалог напоминает, что закончившийся курс нужно завершать, а не удалять.
- Ежедневных напоминаний о приёме нет (§15).

## Отложено (мелкое)

- Дата записей из анкеты передаётся тем же полем, что и день взвешивания. Лучше отдельное поле.
- ИИ-проверка пока читает `pets.medications`, который может устареть до следующей записи. MR-10 будет читать курсы напрямую.
