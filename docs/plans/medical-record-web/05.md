# MW-05 · Лекарства и курсы

Дата плана: 26 сентября 2026. Статус: план, не отчёт о выполнении.

Прочитать [общие правила](README.md). Зависимость: закрытые MW-01…04. Макеты: medications, medications-empty, medication-new, course в [прототипе](../../design/medical-record-web-v1/index.html).

## Сделать

Использовать addMedications/changeMedication/deleteMedication. Несколько назначений за одно сохранение, дозировка, начало, окончание или постоянный приём. Актуальные/завершённые курсы, остановка сегодня и редактирование.

Синхронизировать отображение с «Принимает сейчас» в медкарте, анкетой и сводкой через существующую серверную модель. Не создавать второй независимый список лекарств. Веб не планирует уведомления о приёме.

## Приёмка

1. Сохранить конечный и постоянный курс; они различаются в списке и сводке.
2. Завершить текущий курс: он остаётся в истории и исчезает из «Принимает сейчас».
3. Дата окончания раньше начала блокируется; ошибка пакетного сохранения не оставляет половину курсов.
4. Перезагрузка и мобильное приложение показывают одинаковые данные.

## Как закрыть этап

Продемонстрировать сценарии приёмки на реальном API с тестовым владельцем и отдельным чужим владельцем для проверки доступа. Для изменённой логики добавить полезные интеграционные/компонентные проверки; не тестировать совпадение CSS с самим собой. Выполнить доступные typecheck/lint и релевантные тесты текущего workspace, указав точные команды и результат.

Создать `docs/verification/medical-record-web-05.md`: commit/окружение, критерий → доказательство, скриншоты 390 и 1440, выполненные тесты, дефекты/непроверенные пункты. Не закрывать критерий без проверки. Не переключаться к следующему этапу при незакрытом обязательном критерии; описать блокер и его минимальное исправление. Не менять опубликованные данные и не деплоить без отдельного запроса.
