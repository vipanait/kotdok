# MW-07 · Сводка для врача и печать

Дата плана: 26 сентября 2026. Статус: план, не отчёт о выполнении.

Прочитать [общие правила](README.md). Зависимость: закрытые MW-01…06. Макеты: summary, dog-summary, print в [прототипе](../../design/medical-record-web-v1/index.html).

## Сделать

Подключить getVetSummary; использовать существующие portable summary helpers и состав данных из спецификации. Страница /pets/[id]/vet-summary: сведения питомца, важное, вес, обработки/прививки, визиты, лекарства. Не копировать native share/print API.

Кнопки «Распечатать» и «Сохранить PDF» открывают диалог печати браузера; для PDF дать короткую инструкцию выбрать «Сохранить как PDF». В печати A4 убрать навигацию, кнопки, тени; повторять заголовки таблиц, не обрезать длинные строки и не разрывать короткую запись. Проверить многостраничную сводку, а не только один пример.

Сводка — данные владельца для врача, не автоматически составленный диагноз. Пустые поля не заменять утверждением об отсутствии болезней.

## Приёмка

1. Сводка совпадает с сохранённой медкартой; у пустого питомца честные состояния «не указано».
2. Печать в Chrome и Safari, A4 в PDF: нет меню, обрезанных таблиц, пустых лишних страниц; кириллица читается.
3. Сводка с 30+ записями корректно переносится; длинное название/заметка не выходит за поля.
4. Чужой petId не открывается ни обычной страницей, ни печатным представлением.

## Как закрыть этап

Продемонстрировать сценарии приёмки на реальном API с тестовым владельцем и отдельным чужим владельцем для проверки доступа. Для изменённой логики добавить полезные интеграционные/компонентные проверки; не тестировать совпадение CSS с самим собой. Выполнить доступные typecheck/lint и релевантные тесты текущего workspace, указав точные команды и результат.

Создать `docs/verification/medical-record-web-07.md`: commit/окружение, критерий → доказательство, скриншоты 390 и 1440, выполненные тесты, дефекты/непроверенные пункты. Не закрывать критерий без проверки. Не переключаться к следующему этапу при незакрытом обязательном критерии; описать блокер и его минимальное исправление.
