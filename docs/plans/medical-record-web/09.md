## Task 1: Сервер и данные — миграции

- Гонка «прочитать и записать»: условие статуса внутри SQL-функций изменения события/визита (`status = 'planned'`) и курса (курс не завершён по дню, переданному сервисом); отказ в той же транзакции → `record_done`. Проверка `refuseDoneChange` остаётся для понятного ответа.
- `complete_health_item`: хранить ключ выполнения и у плана из одной позиции; тот же ключ с другими данными → 409 `conflict`, тот же ключ и те же данные → прежний ответ.
- «Сделано»: пустая клиника/заметка, явно переданные владельцем, очищают плановые значения (различать «не передано» и «передано пустым»); формы веба и телефона и подсказка «останется из плана» обновляются.
- `pet_medications`: позиция в пакете; повтор пакета возвращает курсы в порядке ввода; тест MW-05 снова проверяет порядок.
- Вес: необязательный `Idempotency-Key` у POST/PATCH веса (аддитивно в контракте и OpenAPI), клиент API отправляет его, веб и телефон держат ключ как у других форм; повтор после смены дня не создаёт второго измерения.
- «Уточнить» у веса анкеты без истории: указание даты переносит недатированное значение на дату, а не оставляет две строки.
- Завершённый курс: сервер защищает по дню владельца — необязательный `today` (в окне `clientToday`) у изменения курса; без него — прежнее окно.

Приёмка: интеграционные тесты на каждый пункт, включая параллельные запросы для гонок; миграции проходят на локальной базе с данными демо и фикстур; `db push --dry-run` не выполнять (нет доступа) — перечислить файлы миграций для владельца.

## Task 2: День владельца, статусы 404, API

- Где день идёт по UTC (MW-08, решение c): `GET /health` (`pet.medications`, «Принимает сейчас» анкеты), `p_today` синхронизации списка анкеты у операций с курсами и визитами, контекст анализа проверки — принимать необязательный день владельца (в окне `clientToday`), веб и телефон его отправляют.
- Настоящий HTTP 404: несуществующая запись внутри своего питомца, `?check=` чужой проверки, `/checks?pet=<чужой/удалённый>`.
- Возврат после входа и после согласия (#51) на исходную подстраницу (`/edit`, `/health/…`, `/vet-summary`), а не на медкарту: гейт получает настоящий путь.
- OpenAPI: `reauth_required` (401) у `POST /account-deletion` и других мест, где общий 401 его затирал.
- Клиент API: неизвестный код ошибки в ответе не превращается в `internal_error` — сохраняются статус и сообщение, чтобы будущие коды не ломали старые сборки.
- «Сроки» (`/pets/due`): вид визита доступен строке срока (аддитивно), строка называет срок как §7.1.

## Task 3: Веб — формы и медкарта

- Форма «Сделано»: отдельное подтверждение перед сохранением (правила передачи: «фактическая дата, проверка, подтверждение»); подсказка следующей даты не говорит о предложении, если его нет; предупреждение без «препараты».
- После сохранения записи возвращать к разделу/источнику с уведомлением (правила передачи), запись открывается из уведомления.
- Кнопка «Назад» браузера в изменённой форме спрашивает о потере изменений.
- Открытая форма изменения не пересоздаётся при фоновом обновлении; «сегодня» страниц и форм переходит через полночь; день в карточке «История проверок» — от дня страницы.
- Экран «История проверок питомца» по макету pet-history, если его нет.
- Удаление позиции не открывает поиск справочника (фокус на соседнюю позицию или кнопку добавления); вспомогательная ссылка баннера ≥ 44 px.
- Своё название без интервала: веб подставляет запасной интервал, как телефон (общее правило `fallbackInterval`).
- Английский: месяц в доступном имени «Сделано» не в нижнем регистре.
- Курс: нейтральный текст, когда сервер не принимает запись лекарств.
- Вес: смена периода объявляется (постоянная live-область); вес анкеты с двумя знаками можно перенести на дату без изменения значения (общее правило, телефон тоже).
- Возраст 0 в шапке — одинаково с телефоном по спецификации.

## Task 4: Печать сводки

- Проверки в сводке — одной строкой (§7.17).
- «Мурка» помещается на одну страницу A4, если данные это позволяют (§ сводки: 1–2 страницы).
- Подвал в Chrome не дублируется на последней странице, при этом дисклеймер остаётся в браузерах без полей страницы.
- Safari iOS: имя PDF не теряет «.2026»; заголовок раздела не остаётся внизу страницы.

## Task 5: Телефон — паритет

- Дата начала нового курса обязательна, как в вебе (§7.12); пустая допустима только для курса из анкеты.
- Предупреждение «курс сохранится завершённым» (как `endsByToday` веба); проверка длин полей визита до отправки.
- `heldReadOnly` не обещает «добавить в лекарства», если нечего добавить; заголовок заблокированного экрана записи — по виду записи; после «уже отмечено раньше» — ссылка на запись.
- Вес с двумя знаками и возраст 0 — те же общие правила, что в Task 3.
