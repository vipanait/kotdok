## Сделать

Использовать addWeight/changeWeight/deleteWeight, текущие схемы WeightInput/WeightPatch. Сделать график и доступную текстовую историю: одна точка, несколько точек, отсутствие измерений. Периоды графика реально фильтруют данные.

Добавить форму измерения и редактирования с валидацией по контракту, подтверждение удаления. Разбирать русскую десятичную запятую без потери точности. Будущие даты запрещены. После сохранения обновлять историю, последнее значение в шапке и анкету согласно серверной модели.

## Приёмка

1. Добавить 4,2 кг, перезагрузить: значение и дата сохранены.
2. Изменить и удалить последнее измерение: шапка и график показывают актуальные значения.
3. Пустое/нулевое/отрицательное/слишком большое значение и будущая дата отклоняются по контракту.
4. Период без измерений и одна точка отображаются осмысленно; даты и значения читаются без графика.

## Как закрыть этап

Продемонстрировать сценарии приёмки на реальном API с тестовым владельцем и отдельным чужим владельцем для проверки доступа. Для изменённой логики добавить полезные интеграционные/компонентные проверки; не тестировать совпадение CSS с самим собой. Выполнить доступные typecheck/lint и релевантные тесты текущего workspace, указав точные команды и результат.

Создать `docs/verification/medical-record-web-02.md`: commit/окружение, критерий → доказательство, скриншоты 390 и 1440, выполненные тесты, дефекты/непроверенные пункты.
