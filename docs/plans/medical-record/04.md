# MR-04. Справочник вакцин

> Для исполняющего агента: прочитать [общий план](README.md), исходную спецификацию и выполнить только этот этап через `superpowers:executing-plans`. Следующий этап не начинается автоматически.

**Цель:** Вакцину можно выбрать из списка; цели и следующий срок подставляются автоматически. Ручной ввод остаётся рабочим.

**Зависит от:** 03.

**Макеты:** М7, М15, X-catalog-empty, X-catalog-error, X-components.

**Архитектура:** вертикальный этап: контракт → сервер/хранение → мобильный UI → проверки. Новые серверные маршруты входят в `/api/v1`; UI использует общий API-клиент.

**Стек:** текущие Expo/React Native, Next.js API, PostgreSQL, Zod, Vitest. Версии и инструкции проверяются в репозитории перед кодом.

- [ ] Создать тестовые сценарии по MR-04.1…4 ниже; для логики данных сначала воспроизвести отсутствие/ошибку поведения на минимальном тесте.

- [ ] Хранить в записи снимок названия/целей/интервала, чтобы обновление справочника не переписывало историю и существующие планы.
- [ ] Добавить шторку без автофокуса: популярные, поиск по названию/производителю с нормализацией регистра и раскладки; пустой результат и ошибка не блокируют ручной ввод.

- [ ] Подготовить тестовое наполнение из спецификации отдельно от проверенного справочника. Включать реальные продукты для пользователей только после ветеринарного подтверждения состава и интервала.

- [ ] Сверить UI с указанными артбордами; записать доказательства для каждого критерия в `docs/verification/medical-record-04.md`. Отдельно записать то, что проверить не удалось.
- [ ] Представить рабочий результат этапа на приёмку. Незакрытые критерии означают, что этап не завершён.

## Нумерованные критерии приёмки

- [ ] **MR-04.1** Собачий препарат не попадает в выдачу кошке и отклоняется сервером даже при подмене product_id.
- [ ] **MR-04.2** Поиск «нобив», разный регистр, производитель и неверная раскладка находят нужные строки.
- [ ] **MR-04.3** Смена вакцины обновляет цели/дату; изменение справочника не меняет сохранённую историю.
- [ ] **MR-04.4** При недоступном справочнике сохранение своего названия/целей работает.
