## Состояния без отдельного PNG

При реализации не терять их из существующего кода:

- OAuth: ожидание браузера, возврат, отмена и ошибки каждого из трёх провайдеров.
- Регистрация: ошибочный/занятый email, слабый пароль, доставка письма, отсутствие согласия.
- Восстановление: нейтральный ответ о письме, недействительная/просроченная ссылка.
- Загрузка списков, offline, ошибки запросов; скелетон вместо ложного empty state.
- Ошибки полей профиля, сохранения и удаления, подтверждение и отмена, несохранённые изменения.
- Проверка: 401, 402, некорректное описание, повтор, потеря связи; сохранять ввод.
- Дополнительная проверка: approved с балансом и approved уже израсходованная; отправка и ошибка запроса.
- Результат: видовые предупреждения, дополнительные сведения и наблюдения по фото показываются только при наличии данных; тексты из API.
- Отзыв: выбор оценки, необязательный комментарий, сохранение/ошибка и текущее поведение повторного отзыва.
- Удаление аккаунта: гостевой просмотр, повторный вход, accepted с квитанцией, выполняется, завершено, ошибка.
- Админ: проверка роли на сервере, загрузка и ошибки статистики, все текущие периоды.

Это список обязательной сохранности функционала. Комплект является первым предложением оформления, а не исчерпывающей спецификацией каждой ошибки backend.
