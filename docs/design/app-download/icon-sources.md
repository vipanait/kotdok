# Значки мобильных кнопок

- `apple-mark.svg`: геометрия AppleMark из существующего `apps/web/src/components/ui/ProviderMarks.tsx`, заливка изменена на белую для тёмной кнопки. Исходный источник проекта — Apple Design Resources; сведения в комментарии компонента.
- `google-play-mark.svg`: Google Play из Simple Icons 15.0.0, https://cdn.jsdelivr.net/npm/simple-icons@15.0.0/icons/googleplay.svg ; геометрия сохранена, добавлена белая заливка.

Это отдельные значки в пользовательской кнопке, а не официальные бейджи магазинов.
