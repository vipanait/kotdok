# Мультяшные иллюстрации «Лапки» — вариант 2

Набор для сравнения, 20 октября 2026. Оригинальные ресурсы приложения не заменены.

Стиль: два пользовательских референса — простые мультяшные формы, тонкий тёплый коричневый контур, плоские кремовые и золотистые цвета, закрытые улыбающиеся глаза, минимум теней, без реалистичной шерсти.

Создано встроенным ImageGen. Для каждой картинки переданы оба стилевых референса. Для собаки, лежанки и лапки дополнительно использованы оригинальные картинки приложения как референсы композиции.

## Набор и задания генерации

- `welcome-pets.png`: кремовый полосатый кот слева и золотистый щенок справа, сидят в полный рост; маленькие веточки шалфейного цвета и коралловое сердечко, как в референсе.
- `avatar-cat.png`: голова и верх груди улыбающегося кремового кота, несколько серо-бежевых полосок, тонкие усы, светлый круг как в референсе.
- `avatar-dog.png`: парный аватар золотистого щенка с висячими ушами, улыбающимися закрытыми глазами и маленьким розовым язычком, тот же светлый круг.
- `pets-together.png`: тот же кот слева и щенок справа в общей овальной кремовой лежанке с маленькой бирюзовой биркой; кот опирается лапами на бортик, щенок кладёт на него подбородок.
- `paw.png`: кремовая лапка подушечками к зрителю, одна большая и четыре маленькие розовые подушечки. Дополнительная иллюстрация из веб-приложения.

У всех PNG прозрачный фон вне иллюстрации; у аватаров светлый круг является частью изображения. Логотипы и интерфейсные иконки не относятся к этому набору персонажей.
