# Проверка дизайн-концепции v1.1

Дата: 7 сентября 2026. Объект проверки — локальные макеты; не работающее мобильное приложение и не этап API roadmap.

## Экспорт

- 42/42 артборда отрисованы в Chrome через Playwright.
- Nunito и Manrope загрузились; все изображения декодировались.
- JavaScript-ошибок при отрисовке и прохождении маршрутов: 0.
- Горизонтального переполнения на ширине 390: 0 экранов.
- PNG видимой области: 780 × 1688. Для длинных экранов дополнительно сохранены `-full.png`.
- Дополнительные скриншоты 360 × 640: [пустой список](screens/05-360.png) и [экстренный результат](screens/12-360.png). Пустой блок вместе с кнопкой и блок срочности соответственно помещаются в видимую область без прокрутки.

## Пройденные маршруты

1. Заставка → Вход → Регистрация → Письмо → Вход → Пустой список → Добавление → Карточка → Проверка 1 → Проверка 2 → Ожидание → Экстренный результат → Отзыв → Отправка → Питомцы. **Пройден.** Уровень срочности при открытии и отправке отзыва не меняется.
2. Заставка → Вход → Список → Профиль → История → Результат → Питомцы → Карточка → Удаление → Пустой список. **Пройден.**
3. Собака → Питание → «Не указано» → Собака. **Пройден**, выбранное значение сбрасывается.

Проверены именно локальные переходы между демонстрационными артбордами. Реальных сетевых запросов нет.

## Визуальный просмотр

Просмотрены общий обзор, вход с иллюстрацией, раскрытый образ жизни собаки и полный второй шаг. Все шесть итоговых иллюстраций имеют настоящий альфа-канал. Проверены на белом, светло-бирюзовом и тёмном фоне; фоновых масок и multiply нет. Вкладка «Питомцы» на всех экранах использует нейтральный отпечаток лапы, карточки — прозрачные видовые аватары. Иконки и тексты срочности различаются без опоры только на цвет. Карточки списка сохраняются под сообщением «Нет связи с сервером».

## Что ещё проверить при реализации

- VoiceOver/TalkBack и правильные accessibility labels.
- Dynamic Type / системный шрифт 200%, включая длинные подписи и кнопки.
- Клавиатуру, сохранение черновика, отказ от потери несохранённых изменений.
- Android Back, восстановление сессии и замену ожидания результатом в стеке.
- Реальные API-ошибки, отсутствие данных, разные длины ответов и условное включение запроса дополнительной проверки.
- Производительность изображений и Reduce Motion на устройстве.

Машинные результаты: [render-report.json](render-report.json). Это проверка комплекта дизайна; мобильный этап разработки не объявляется завершённым.
