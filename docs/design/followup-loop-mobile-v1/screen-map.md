# Карта мобильных экранов

| Бриф | Артборды | Содержание и источник |
|---|---|---|
| М-1 | result, urgent, permission | Результат с карточкой, срочный вариант с выключенным переключателем, неразрешённые уведомления. CheckResult.tsx; check + case + локальное разрешение. |
| М-2 | sheet | Нижняя шторка объясняет разрешение. Разрешить показывает демо-подтверждение, ОС не вызывается. |
| М-3 | notification | iOS-уведомление без симптомов, переход к отметке. Имя и вид питомца. |
| М-4 | mark, filled, visit, error, closed, loading | Пустая/заполненная форма, вопрос о визите, ошибка с сохранённым вводом, закрытый случай, скелетон. Новый экран случая. |
| М-5 | better, same, last, worse, visited, notyet, zero | Все основные исходы. Правила и баланс; новый экран итога. |
| М-6 | pets, pet | Баннер на списке, «Наблюдаем» над «Сегодня» и напоминаниями. pets/index.tsx, pets/[id]/index.tsx, TodayDoses. |
| М-7 | history, timeline | Группировка проверок, лента пяти событий. CheckHistory.tsx и новая страница. |
| М-8 | repeat | Контекст предыдущей проверки над полем, возможность убрать его, цена. Действующий первый шаг формы. |
| М-9 | record, summary | Перенесённый случай, строка в сводке за шесть месяцев. Карточка питомца и сводка врача. |
| FU-08 | photo, compare | Место фото и схема сравнения с датами. Будущий этап, не первая версия. |

## Дополнительные состояния без отдельных артбордов

- Healthy: напоминания нет. Home care: завтра и через 3 дня. Emergency: предложение спросить завтра выключено, основное действие клиники остаётся первым.
- Уведомления запрещены ОС: «Уведомления выключены в настройках» / «Открыть настройки». Ошибка сохранения: возврат переключателя и «Не получилось сохранить. Попробуйте ещё раз».
- Повторная проверка внутри случая: «Часть случая от 23 октября · 2 отметки» вместо переключателя. Проверка старше 12 часов: без нового переключателя. Другой активный случай: объяснить, что включение закроет старый и переключит наблюдение на новый.
- Уведомление urgent/emergency: «Как Мурка? Расскажите, были ли у врача». После эскалации: «Мурка была у врача? Отметьте, что он сказал».
- Отправка: временно заблокированная кнопка «Сохраняем…» показана интерактивно. Ошибка не теряет ввод; серверная идемпотентность — вне макета.
- Недоступная проверка: «Не нашли эту проверку» / «К питомцам». Закрытый случай показывает дату и исход.
- Emergency + «Ещё нет»: «Нужна клиника сейчас», клиника первым действием, снова спросить завтра. В notyet показан urgent.
- Нет активного случая: блок «Наблюдаем» отсутствует. До срока: «Следующий вопрос — завтра в 09:00». Эскалация: «Советуем показаться врачу», клиника первым действием.
- Несколько питомцев: одна карточка на питомца, наиболее ранняя отметка. Скрытие до завтра не закрывает случай.
- Хронология без отметок: «Пока без отметок, спросим 24 октября в 09:00». Длинная лента продолжается без обрезки. Ошибка загрузки даёт повтор. В открытом случае — «Отметить сейчас» и «Не напоминать больше» с подтверждением закрытия без исхода. Основной макет показывает закрытый случай.
- Медкарта: пустой раздел скрыт, больше трёх строк — «Все случаи · N», повторное сохранение не создаёт дубликат.
- FU-08: миниатюры в ленте, полноэкранное листание с датами; compare показывает структуру без настоящих фотографий.

## Тексты EN

Общие новые тексты имеют соответствия в `../followup-loop-v1/screen-map.md`. Мобильные дополнения:

| RU | EN |
|---|---|
| Разрешить уведомления? | Allow notifications? |
| Чтобы спросить, как Мурка, в нужное время. Других уведомлений не прибавится. | To ask how Murka is doing at the right time. This won't add any other notifications. |
| Разрешить / Не сейчас | Allow / Not now |
| Разрешите уведомления, иначе напомним только в приложении | Allow notifications; otherwise we'll remind you only in the app |
| Уведомления выключены в настройках / Открыть настройки | Notifications are disabled in settings / Open settings |
| Как Мурка? Отметьте, стало ли лучше. | How is Murka? Let us know if things have improved. |
| Как Мурка? Расскажите, были ли у врача | How is Murka? Tell us whether you saw a vet |
| Мурка была у врача? Отметьте, что он сказал | Has Murka seen a vet? Record what they said |
| Первое — завтра в 09:00 | First check-in: tomorrow at 9:00 AM |
| Спросим через 12 часов и через 2 дня. Если лучше не станет — подскажем, что делать. | We'll ask in 12 hours and in 2 days. If there's no improvement, we'll suggest what to do next. |
| Вы ещё не были у врача. Спросим ещё раз завтра. | You haven't seen a vet yet. We'll ask again tomorrow. |
| Нужна клиника сейчас | Go to a clinic now |
| Фото по дням | Photos by day |
| При отправке спишется 1 проверка | Submitting uses 1 check |

Даты, имена и заметки — демонстрационные. При реализации использовать локализацию, реальные часовые пояса и склонения имени.
