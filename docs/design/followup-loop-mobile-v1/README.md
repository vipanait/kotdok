# Цикл наблюдения — мобильное приложение, концепция 01

25 октября 2026. Отдельные макеты приложения Expo, не адаптивный веб и не реализация продукта.

Открыть `index.html`. В верхнем меню — 27 экранов, выбор кошки или собаки. В области телефона страницы прокручиваются; системная строка и нижняя навигация остаются на месте. Ответ → итог → сохранение в медкарту работает как локальная демонстрация. Настоящие уведомления, данные, фото и проверки не создаются.

## Решения

- Сохранены актуальные мобильные токены: Nunito/Manrope, сливочный фон, белые карточки, бирюзовое действие и палитра срочности.
- Три вкладки соответствуют `apps/mobile/app/(tabs)/_layout.tsx`: питомцы, проверка, профиль. Стартовый экран — питомцы; отдельного «Обзора» нет. В прототипе вкладка «Профиль» сокращённо ведёт к истории, существующему сценарию внутри профиля.
- На результате сначала исходное описание, как в текущем CheckResult; затем срочность, клиника при необходимости и новая карточка наблюдения. Срочное напоминание — после записи визита.
- Отметка открывается самостоятельным экраном, пригодным для перехода из уведомления. Три крупные кнопки с выбранными пользователем иллюстрациями и необязательная заметка. Итог — следующий экран, не веб-колонка.
- Иллюстрации из `../followup-loop-v1/assets/pet-moods.png`: два вида × три состояния. Вид определяется выбранным демо-питомцем; в реализации — фактическим видом питомца. Фото питомца в профиле должно иметь приоритет перед аватаром-заглушкой.
- После эргономического ревью форма прокручивается отдельно, кнопка «Отметить» закреплена над вкладками. Необязательная заметка раскрывается по нажатию, при наличии текста открыта сразу. При большом тексте и открытой клавиатуре нужны реальные safe-area и keyboard avoidance в приложении; HTML это не подтверждает.
- Время ночной отметки перенесено на 09:00. Промежуточный итог использует абсолютную дату следующей отметки, а не двусмысленное «ещё через 2 дня».
- Экран блокировки и системная строка — иллюстрация iOS, не пиксельная спецификация ОС. Android использует платформенные системные области.

## Комплект

- 27 экранов в 390 × 844: `имя.png` — видимая область, `имя-full.png` — весь экран с прокручиваемым содержимым.
- `mark-dog.png` — собачий вариант.
- `overview.png` — обзор шести ключевых экранов.
- Три проверки с текстом 200%: `*-large-text.png`.
- `render.cjs` и `render-report.json` — воспроизводимая проверка макетов.
- `screen-map.md` — покрытие брифа и дополнительные состояния.

Медицинские рекомендации существующей проверки сокращены до обозначенных мест, чтобы не сочинять медицинский ответ. Полная форма повторной проверки не перерисована: показано изменение её контекста. FU-08 имеет место загрузки и схему сравнения; реальных клинических фото нет.
