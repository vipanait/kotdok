# Аудит форм · 26 сентября 2026

Проверены формы и связанные переходы веб-медкарты. Правило владельца об отсутствии редактирования сделанного имеет приоритет над исходным вариантом макетов и старой спецификацией.

| Область | Найдено | Исправлено в прототипе |
|---|---|---|
| Сохранённые прививки/обработки | Записи вели в общую форму, некоторые даты совпадали ошибочно | У каждой отдельный просмотр с её датой и препаратами |
| Выполненные процедуры | Была кнопка редактирования | Убрана; старые edit-адреса показывают просмотр |
| Планы | Просмотр смешивался с созданием | Отдельно просмотр, изменение с предзаполнением, выполнение |
| Многопозиционная прививка | Выполнение могло затронуть обе позиции | Выбор конкретной прививки перед выполнением; разные кнопки в сроках |
| Новая процедура | Демонстрационные позиции могли выглядеть как чужие готовые данные | Переход «Добавить» очищает позиции и клинику, открывает справочник; заполненные артборды остаются примерами ввода |
| Переключение Сделано/План | Терялись позиции, следующая дата оставалась у плана | Переключение внутри формы; позиции сохраняются, будущий срок отключается у плана |
| Следующая дата | «Своя дата» не открывала поле | Явное необязательное поле даты, можно очистить; проверка относительно фактической даты |
| Ручная запись | Кошачьи цели предлагались обработкам, всё было выбрано | Цели по виду записи и питомцу, изначально не выбраны; требуется название или цель |
| Лекарства | Две заполненные позиции при создании, нерабочий «Постоянно» | Одна пустая позиция, новые по нажатию, окончание скрывается/отключается при постоянном приёме |
| Курсы | Завершённый открывался как новый; текущий — двумя лекарствами | Завершённый только просматривается, текущий редактируется отдельно |
| Визит | Новая форма имела старый диагноз, назначения и проверку | Новая форма без этих данных; из результата отдельный контекст; план и состоявшийся визит разделены |
| Назначения | Повтор заголовка, тесные отступы, ненужная линия | Один заголовок раздела, отступы 32/16 px, удаление своей позиции, без линии над действиями |
| Вес | Все «Изменить» вели на 12 сентября / 4,2 кг | Индивидуальные формы для марта, июня, сентября; новый вес пустой |
| Питомец | Из пустых разделов Бобика открывалась Мурка | Контекст питомца передаётся в новые формы; вес и справочник относятся к выбранному питомцу |
| Лимиты | Отсутствовали ограничения некоторых полей | Ограничения длины по contracts, до 10 добавляемых позиций, проверка дат курса |

## Новое продуктовое правило

Выполненные события прививок/обработок и состоявшиеся визиты нельзя редактировать. Запланированные можно. Текущий курс допускает правки/завершение; завершённый — просмотр. Вес и анкета сохраняют своё обычное редактирование. Удаление ошибочной записи остаётся отдельным подтверждаемым действием.

Backend пока позволяет PATCH сделанного: запрет надо реализовать и проверить в этапах MW-03/04/06, включая влияние на mobile. Дизайн не меняет действующие API. После сохранения нового выполненного события показать просмотр, а не оставить редактируемую форму. Само сохранение в этом локальном прототипе демонстрационное.

## Что остаётся задачей реализации

Полное сохранение/загрузка, изоляция владельца, даты и часовой пояс, server-side ограничения, idempotency и атомарность, подсказки клиник/лекарств, выбор из реальных проверок, сохранение черновика при навигации, полноценная доступность combobox/модалок, ошибки API и несохранённые изменения описаны в плане. Прототип не выдаётся за реализацию этих функций. Ручное добавление и сохранение показывают демонстрационное сообщение, данные не записываются в базу.

Проверки прототипа: все экранные состояния на 320/390/1024/1440 px; сценарии неизменяемой выполненной записи, изменения/отмены плана, переключения режима, добавления лекарства и постоянного курса, выбора конкретного веса. Свежие результаты — render-report.json. Реальные функции принимаются по MW-01…08.
