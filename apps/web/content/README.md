# Статьи о симптомах и отравлениях

Один JSON-файл — одна страница сайта:

- `symptoms/<slug>.json` → `https://lapka.my/simptomy/<slug>`
- `toxins/<slug>.json` → `https://lapka.my/otravlenie/<slug>`

Схема — `src/features/seo-content/schema.ts`, проверки — `tests/unit/seo-content/`. Образец — [`symptoms/rvota-u-koshki.json`](symptoms/rvota-u-koshki.json). План и список тем — `docs/plans/seo-symptom-pages/README.md`.

## Как появляется текст

1. Черновик пишет модель: `review.status: "draft"`, `draftedBy: "model"`.
2. Второй агент проверяет его по правилам ниже, правит и ставит `"agent_reviewed"`, `reviewedBy: "agent"`, `reviewedAt`, `nextReviewAt` (+12 месяцев).
3. Владелец публикует: `"published"`. Слияние в `main` выкладывает страницу на сайт.

Production показывает только `published`. Предпросмотр Vercel и `next dev` показывают и черновики — с плашкой и `noindex`.

Ветеринар тексты не подписывает, поэтому страница нигде не говорит, что её проверил врач.

## Главное правило формулировок

Страница — информационная проверка симптомов, не ветеринарная консультация и не диагноз. Так же говорит само приложение: «Лапка — информационный инструмент. Не является ветеринарным диагнозом и не заменяет осмотр специалиста.»

- Пишем «возможные причины», «может быть связано с», «врач может проверить». Не пишем «у вашей кошки X», «это точно Y».
- Нет слов «диагноз», «диагностировать», «вылечить», «назначьте». Тест ищет их (`FORBIDDEN_WORDS`).
- Никаких доз, названий препаратов для самостоятельного приёма, лекарств для людей, «народных средств». Про лекарства — только «не давайте без назначения врача».
- Не советуем вызывать рвоту, кроме фразы «только по указанию врача».
- При сомнении — более срочный уровень.
- Страницы кошки и собаки на одну тему различаются по существу: свои причины, признаки, пороги. Не копируем текст с заменой слова.

## Уровни срочности

Те же, что в приложении (`src/server/symptom-check/analyze-symptom-check.ts`, словарь `urgency` в `src/shared/i18n/dictionaries/ru.ts`). Название и инструкцию уровня страница берёт из словаря; в JSON пишем только признаки.

| Ключ | На сайте | Инструкция |
|---|---|---|
| `emergency` | ЭКСТРЕННО | Немедленно в ветеринарную клинику |
| `urgent` | СРОЧНО | К ветеринару в течение 24 часов |
| `monitor` | НАБЛЮДАЕМ | Наблюдайте 48 часов, при ухудшении — к врачу |
| `home_care` | ДОМАШНИЙ УХОД | Можно лечить дома |
| `healthy` | ВСЁ В ПОРЯДКЕ | Ничего делать не нужно |

Ориентиры из правил анализа.

Кошки — ЭКСТРЕННО: судороги, затруднённое дыхание, закупорка мочевых путей у котов, обморок, подозрение на отравление, травма. СРОЧНО: не ест больше суток, рвота больше трёх раз, кровь в моче или кале, прячется и вялая, заметная потеря веса. НАБЛЮДАЕМ: однократная рвота, лёгкое чихание, небольшое изменение аппетита. ДОМАШНИЙ УХОД: мелкие ранки, редкие комки шерсти, обычные изменения в груминге. ВСЁ В ПОРЯДКЕ: обычное для кошки поведение или единичное безобидное событие.

Собаки — ЭКСТРЕННО: судороги, затруднённое дыхание, подозрение на заворот желудка (безрезультатные позывы на рвоту и вздутый живот), обморок, подозрение на отравление (ксилит, шоколад, виноград, родентициды), травма, тепловой удар, бледные дёсны, непрекращающееся кровотечение. СРОЧНО: не ест больше суток, рвота больше трёх раз, кровь в моче или кале, выраженная вялость, сильная хромота или боль, рвота или понос у щенка (риск парвовируса), внезапная смена поведения с признаками боли. НАБЛЮДАЕМ: однократная рвота, слегка мягкий стул, небольшое изменение аппетита, лёгкая хромота после игры, которая проходит. ДОМАШНИЙ УХОД: мелкие ссадины, лёгкий зуд после известного аллергена без беспокойства, скованность после прогулки, которая проходит. ВСЁ В ПОРЯДКЕ: обычное для собаки поведение или единичное безобидное событие.

## Поля страницы симптома

| Поле | Что писать |
|---|---|
| `kind` | `"symptom"` |
| `slug` | из таблицы тем в плане; латиница и дефисы |
| `locale` | `"ru"` |
| `species` | `"cat"` или `"dog"` |
| `topic` | общий для пары кошка/собака: `rvota`, `ponos`… |
| `bodySystem` | `digestive`, `urinary`, `breathing`, `skin`, `eyes_ears`, `mouth`, `nervous`, `movement`, `general` |
| `name` | коротко, для хабов: «Рвота» |
| `title` | H1: «Рвота у кошки: когда срочно к врачу» |
| `metaTitle` | до 60 знаков, без «— Лапка» (добавится само) |
| `metaDescription` | до 160 знаков |
| `shortAnswer` | 2–3 предложения, 40–70 слов: когда наблюдать, когда в течение суток, когда срочно |
| `signs` | признаки по пяти уровням; `emergency`, `urgent`, `monitor` — хотя бы по одному; `home_care` и `healthy` могут быть пустыми, если честно нечего сказать |
| `quiz` | 5–7 вопросов «да/нет»; у каждого `level`: `emergency` или `urgent`; хотя бы один каждого уровня; вопрос понятен без страницы, одна мысль в вопросе |
| `causesByAge` | `young` (котёнок/щенок), `adult`, `senior`: частые возможные причины, по 2–5 |
| `homeSteps` | безопасные шаги до визита, 2–6 |
| `avoid` | чего не делать, 2–5 |
| `tellVet` | что рассказать врачу, 3–7 |
| `faq` | 3–5 вопросов, как их задают в поиске, ответ 1–3 предложения |
| `related` | 2–6 slug других страниц из плана (симптомы или отравления) |
| `sources` | 1–3 источника; только название (`title`), `url` — только если адрес точно существует |
| `review` | `{ "status": "draft", "draftedBy": "model" }` |

Блок «Это срочно?» сам никогда не выдаёт ДОМАШНИЙ УХОД и ВСЁ В ПОРЯДКЕ: без «да» результат — НАБЛЮДАЕМ. Поэтому вопросы — только о тревожных признаках.

## Поля страницы отравления

Общие поля те же (`slug`, `locale`, `title`, `metaTitle`, `metaDescription`, `shortAnswer`, `quiz`, `tellVet`, `faq`, `related`, `sources`, `review`), плюс:

| Поле | Что писать |
|---|---|
| `kind` | `"toxin"` |
| `name` | «Лилия» |
| `whereFound` | где встречается вещество: букеты, шоколадные конфеты, жвачка без сахара… |
| `bySpecies.cat`, `bySpecies.dog` | `risk` — насколько опасно для вида (без доз и расчётов), `signs` — признаки отравления; раздел вида не пишется, если для него тема не актуальна |
| `firstSteps` | что сделать сразу: звонить в клинику, взять упаковку, не ждать признаков |
| `avoid` | чего не делать: не вызывать рвоту без указания врача, не давать молоко и «антидоты» |

Для отравлений почти все вопросы блока — уровня `emergency`: съело или могло съесть — уже повод звонить в клинику.
